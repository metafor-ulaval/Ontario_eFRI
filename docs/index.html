1 Introduction

In recent years, many Canadian provinces have acquired airborne lidar data covering a large part of their territory. This technology makes it possible to redefine the description of forest attributes. Indeed, numerous initiatives have been carried out since the dissemination and democratization of lidar data and its derivative products.

1.1 Objective

The objective of this project is to automatically generate polygons that describe the forest stand. Both the delineation and description are done automatically through a series of steps that are described in the document. This project is a continuation of Ethan Berman’s work at the University of British Columbia, which was conducted in 2023. Details are available on this page : https://bermane.github.io/ontario-inventory/index.html. The main improvement over previous work is that most of the steps have been integrated into a package, simplifying and standardizing them. The package is called eFRItools and is available here: https://github.com/metafor-ulaval/eFRItools. All the functions can be used for other purposes that concern automated forest stand segmentation and forest attribute characterization.

1.2 Study area

The study area is located in the province of Ontario, in Canada. Romeo Malette Forest is located in the middle of the province and is therefore coniferous.

1.3 Step

The steps for generating ecoforest polygons are as follows:

  1. Segmentation based on lidar metrics (section 2)

  2. Extrapolation of forest composition variables using a k-nearest neighbor (kNN) imputation algorithm (section 3):

    • Leading species : LEADSP

    • Second species : SECSP

    • IThree functional group class : FUNCTIONAL_GROUP_3

    • Five functional group class : FUNCTIONAL_GROUP_5

  3. Construction of the attribute table to obtain the following attributes, for each polygon forest stand (section 4):

    • Source of data : SOURCE

    • Year of produced data : YRSOURCE

    • Area : AREA

    • Perimeter : PERIMETER

    • Proportion forested : PROPFORESTED

    • Most frequent landcover type : POLYTYPE

    • Most frequent landcover proportion : POLYTYPEPROP

    • Forest age : AGE

    • Year of last perturbation : YRDEP

    • Type of last perturbation : DEPTYPE

    • Proportion of last perturbation : DEPPROP

    • Year of most widespread harvest : YRHARVEST

    • Proportion of most widespread harvest : HARVESTPROP

    • Year of most widespread forest fire : YRFIRE

    • Proportion of most widespread forest fire : FIREPROP

    • Merchantable volume per hectare : VMERCH_HA_MEDIAN

    • Quadratic mean diameter at breast height : QMDBH_MEDIAN

    • Number of stems with DBH > 7.1 cm per ha : DENS_MEDIAN

    • Average tree height weighted by basal area : LOR_MEDIAN

    • Basal area, tree cross sectional area (approximated as a circle) at breast height : BA_HA_MEDIAN

    • Height of forest stand based on median z_p95 : HEIGHT

    • Canopy cover based on median z_above2 : CANOPY_COVER

    • Forest density based on median fractional cover between 50 and 200 cm : DENSITY

    • Median slope : SLOPE

    • Soil moisture based on SAGA wetness index : MOISTURE

2 Segmentation

2.1 Segmentation basics

The first step is to create polygon that will represent homogeneous forest stand. To perform this task, the Generic Region Merging tools from Orfeo ToolBox (OTB) is used. Three method can be used in this tools : Baatz & Schape, Eclidean Distance, and Full Lambda. For this work, the Baatz & Schape criterion method was used. This algorithm is the same used in the Multi-resolution Segmentation by the well known software eCognition and thus made it freely accessible. This algortihm works by merging iteratively small region together based on dissimilarity of spectral values. There is three parameters that control size and shape of resulting segments : threshold, weight of spectral homogeneity and weight of spatial homogeneity. Here is how these parameters influence segmentation:

  • The threshold control maximum heterogeneity allowed when merging, controlling how fine or coarse the segmentation is :

    • Small threshold → fine segmentation (many small regions)

    • Large threshold → coarse segmentation (fewer, larger regions)

  • The weight of spectral homogeneity gives to spectral similarity (pixel values, band means) when deciding whether regions should merge :

    • If high → segmentation will mostly respect spectral values

    • If low → spectral similarity matters little, other criteria (shape) dominate

  • The weight of spatial homogeneity gives to shape similarity (compactness and smoothness) when deciding whether regions should merge :

    • If high → the algorithm favors compact, smooth regions even if spectral similarity is weaker

    • If low → region boundaries will mostly follow spectral homogeneity

Segmentation parameters were calibratedby conducting a sensitivity analysis for 5 differents models with contrasted input metrics [SHOW DIFFERENT MODELS ?] to produce polygon networks of comparable cartographic complexity, defined by polygon size distribution, shape complexity, and polygon density. These criteria were used to ensure that automated delineations remained operationally plausible and comparable to conventional stand maps.

If you need more details about parameters, eCognition made this video to explain parameter selection for their Multi-resolution Segmentation algorithm.

2.2 Segmentation inputs

The inputs consist of lidar metrics computed from raw LiDAR data. LiDAR data have been acquired with a [INSERT ALL SPECS HERE]. Points density is 40 points/m².

For this step, the following metrics are used for polygon segmentation : * z_p95 → Height of 95th percentiles of returns above 1.3 m * z_cv → Coefficient of variation of returns above 1.3 m * z_above2 → Canopy cover of first returns above 2 m

These metrics are only one example of what can be used, but it is important to note that other metrics can be used for segmentation. The metrics used will reflect how the segmentation polygons are divided. Thus, if a spectral index such as NDVI is used, the polygons will tend to separate forest stands with contrasting spectral signatures from this indice. For effective segmentation, it is recommended to use metrics that provide different informations. A correlation matrix or principal component analysis (PCA) can be used to see relationships between metrics.

An additional data used in segmentation are masks where segmentation is therefore not performed. These are typically waterbodies and roads.

2.3 Segmentation results

The segmentation result therefore produces polygons representing forest stands according to the selected metrics. These polygons can therefore be expected to represent homogeneous forest stands based on choosen metrics.

The automated segmented forest stand can be now compared to forest stand inventories. Density plots are used to assess whether the distribution of the size and shape are similar. Based on previous parameters obtained by the sensitivity analysis, the difference between distributions are supposed to be minimal and therefore the automated segmented forest stand should represent operationnaly plausible forest stand that mimic polygons of the forest stand inventorie.

Area in hectare are use for size and shape index, which is determine by this formula : [perimeter/(2sqrt(piarea))] is use to assess shape.

3 Imputation

3.1 Imputation basics

Some attributes can’t be directly extracted from a raster layer containing the information. For example, there is still no layer describing tree species across Ontario. For this tasks, k-nearest neighbor (kNN) imputation can be used to infer what would be some attributes (REF). This widely used method use similarity between variables from two different datasets. In order to fill a missing data, the algorithm identifies the k most similar observations based on distance of common variables. The missing values are then estimated using the corresponding values from these neighbors, often by taking their mean (for numerical variables) or mode (for categorical variables).

To identify the most suitable variables for kNN imputation, a performance analysis was conducted using all possible combinations of five uncorrelated variables. This analysis evaluated, for each combination, how accurately the imputed values matched the observed values of the forest polygon inventory. Therefore, the optimal combination of metrics depends on the specific variable being imputed :

  • Imputed leading species : dem, rumple_index, z_kurt, z_p95, B6

  • Imputed second species : dem, rumple_index, sagawi, z_p95, NDVI

  • Imputed three functional group class : dem, relative_topographic_position_100m, rumple_index, z_p95, B6

  • Imputed five functional group class : dem, rumple_index, slope, z_p95, B6

In addition, for each of these 4 variables, the X and Y coordinates of polygon centroid have been used for the imputation.
